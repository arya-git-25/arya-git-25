FAQ

Common questions

Short answers. Message me for anything else.

Next.js or Astro: which should I choose?

Astro for content and marketing sites that should be as fast as possible; Next.js for apps and portals with lots of interactive search and user features.

Can you move my React site to server rendering?

Yes. I did this for elysian.com, moving from a React single-page app to Astro on Cloudflare so every page is readable by search engines.

Do you host on Vercel?

Yes, or Cloudflare. I pick based on cost, region and what your site needs.
